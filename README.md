# Lumivara Online — Android Client

ไคลเอนต์สำหรับเล่น Lumivara Online บน Android ใช้ Android System WebView พร้อมเต็มจอแนวนอน หน้าต่างเกมขนาดเล็ก และเมนูภาษาไทย/อังกฤษ

## ดาวน์โหลด

ดาวน์โหลด APK จาก [Releases ล่าสุด](https://github.com/newkiss2582/LumivaraOnline-APK/releases/latest)

รุ่นปัจจุบัน **v1.15.0** เลือกไฟล์ **Lumivara-Online-Android-1.15.apk** ที่ [หน้า Release v1.15.0](https://github.com/newkiss2582/LumivaraOnline-APK/releases/tag/v1.15.0)

รองรับ Android 8.0 ขึ้นไป การเปิดหลายโปรไฟล์แยกไอดีใช้ Android 9 ขึ้นไป

## ความสามารถ

- เล่นเกมเต็มจอแนวนอน
- เปิดจอเล็ก ลากย้าย และปรับความกว้าง/ความสูงได้
- ย่อเป็นปุ่มลอยแล้วเปิดหน้าเกมเดิมต่อ
- เปิดได้สูงสุด 4 โปรไฟล์แยกพื้นที่ข้อมูลบัญชี
- จัดเรียงจออัตโนมัติ และเปิด/ปิดแต่ละโปรไฟล์จากเมนูจัดการ
- เลือกภาษาเมนูแอป: ไทย / English / ตามภาษาเครื่อง
- ดูคลิปสอนติดตั้งและตั้งค่าจากในแอปโดยไม่ใช้เน็ต
- ตรวจสถานะเกมและการเชื่อมต่อ พร้อมคัดลอกรายงานทางเทคนิค

## อัปเดต v1.15.0

เพิ่มตัวช่วย timer ตรวจการเชื่อมต่อและลองเชื่อมต่อใหม่ขณะพับแอปหรือดับจอ ใช้เวลาจริงและไม่ยิงคำสั่งย้อนหลังเป็นชุด เพิ่มหน้ารายงานแยกตามโปรไฟล์ และปุ่มตั้งจอดำประหยัดพลังงานของเกมเป็น “ไม่เปิดเอง”

การปรับครั้งนี้ยังต้องทดสอบบนเครื่องจริง ไม่รับประกันจำนวนมอนเท่าตอนเปิดเกมบนจอ Android เครือข่าย และเซิร์ฟเวอร์ยังมีผลต่อการทำงาน

## ติดตั้งหรืออัปเดต

1. ดาวน์โหลด APK จาก Releases แล้วเปิดไฟล์
2. อนุญาตติดตั้งจากแหล่งนี้ หาก Android ร้องขอ
3. หากใช้ APK WebView รุ่นเดิมของโครงการ ให้ติดตั้งทับ **ไม่ต้องถอนแอปหรือเคลียร์ข้อมูล** เพื่อเก็บข้อมูลเกมและบัญชี Guest
4. เปิดแอป อนุญาตแสดงทับแอปอื่นและการแจ้งเตือนตามขั้นตอนในแอป
5. ตั้งค่าการทำงานเบื้องหลัง/แบตเตอรี่ตามคำแนะนำของเครื่อง
6. เลือกโปรไฟล์ แล้วเปิดเกมแบบเต็มจอ หน้าต่างลอย หรือปุ่มลอย

## ปิดและจัดเรียงจอ

- **×** ยืนยันก่อนปิดเฉพาะจอนั้น ข้อมูลล็อกอินยังเก็บไว้
- **−** ย่อเป็นปุ่มลอยโดยเก็บเกมเดิม
- **⋮ → จัดเรียงจออัตโนมัติ** จัดเรียงเฉพาะโปรไฟล์ที่เปิดอยู่ตามพื้นที่หน้าจอ
- **จัดการ / ปิดแต่ละจอ** เปิดหรือปิดโปรไฟล์อื่นได้จากที่เดียว

## เมื่อพับแอปหรือดับจอแล้วเกมเดินช้า

1. ถ้าจอดำประหยัดพลังงานของเกมเปิดอยู่ ให้แตะสองครั้งในเกมเพื่อออก
2. กด **⋮ → ตั้งจอดำของเกมเป็นไม่เปิดเอง** แล้วกดยืนยัน
3. ลองเปรียบเทียบเปิดเกมบนจอ พับแอปจอยังเปิด และดับจอ ในเงื่อนไขใกล้เคียงกัน
4. เมื่อพบปัญหา กด **ตรวจสถานะเกมและการเชื่อมต่อ → คัดลอกรายงาน** เพื่อนำข้อความไปตรวจเพิ่มเติม

รายงานเก็บสถิติในเครื่องทุก 10 วินาที สูงสุด 30 นาที ไม่มีการส่งออกอัตโนมัติ ไม่รวม cookies ข้อมูลบัญชีหรือเนื้อหาแพ็กเก็ต รายละเอียดอยู่ใน README ที่แนบกับ Release

## คลิปสอนติดตั้งและภาษาเมนู

เปิดหน้าตั้งค่า → **▶ คลิปสอนติดตั้งและตั้งค่า** คลิปอยู่ใน APK และอาจแสดงเมนูของรุ่นก่อน

เปิดหน้าตั้งค่า → **ภาษาแอป / App language** เพื่อเลือกไทย English หรือตามภาษาเครื่อง ภาษาในเกมตั้งค่าแยกจากเมนูแอป
